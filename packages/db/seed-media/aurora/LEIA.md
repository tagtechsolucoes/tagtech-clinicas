# Fotos da Clínica Aurora (demonstração)

O seed usa o que estiver aqui; o que faltar fica sem foto. Tudo em WebP.

| Arquivo                                     | Onde aparece                                                                           | Tamanho               |
| ------------------------------------------- | -------------------------------------------------------------------------------------- | --------------------- |
| `capa.webp`                                 | Topo do site                                                                           | 1600 px no lado maior |
| `logo.webp`                                 | Logo (quadrado)                                                                        | 512 × 512             |
| `espaco-1.webp` … `espaco-6.webp`           | Galeria "O espaço" (recepção, consultório, atendimento, sorriso, tecnologia, detalhes) | 1600 px no lado maior |
| `helena.webp`, `rafael.webp`, `camila.webp` | Foto dos profissionais                                                                 | 512 × 512             |

Só fotos com licença para uso comercial (Unsplash, Pexels ou próprias).
